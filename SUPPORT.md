# 💬 Getting Support for Unboilerplate

Welcome to the **Unboilerplate** support guide! Here is where you can find help, ask questions, and connect with other creators.

---

## 📖 1. Documentation & Interactive Studio

Before asking a question, check our documentation and live sandbox:
- **Interactive Playground:** [https://unboilerplate.vercel.app/playground](https://unboilerplate.vercel.app/playground)
- **API Reference & Classes:** [https://unboilerplate.vercel.app/docs](https://unboilerplate.vercel.app/docs)
- **Class Cheatsheet:** [https://unboilerplate.vercel.app/cheatsheet](https://unboilerplate.vercel.app/cheatsheet)
- **Beginner Learning Guide:** [https://unboilerplate.vercel.app/learn](https://unboilerplate.vercel.app/learn)
- **Starter Templates:** [https://unboilerplate.vercel.app/templates](https://unboilerplate.vercel.app/templates)

## 🐛 3. Reporting Bugs & Proposing Features

- If you found a bug or visual defect: [Open a Bug Report](https://github.com/EldrexDelosReyesBula/Unboilerplate/issues/new?template=bug_report.yml)
- If you have an idea for a pure CSS class or component: [Submit a Feature Request](https://github.com/EldrexDelosReyesBula/Unboilerplate/issues/new?template=feature_request.yml)
- If you'd like to suggest an aesthetic movement: [Suggest an Aesthetic Preset](https://github.com/EldrexDelosReyesBula/Unboilerplate/issues/new?template=aesthetic_preset_request.yml)
