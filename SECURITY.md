# 🛡️ Security Policy

## Supported Versions

The following versions of **Unboilerplate** are currently receiving updates and security fixes:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

As a pure CSS framework with zero runtime JavaScript dependencies, Unboilerplate poses minimal server-side or executable execution risk. However, security in CSS is still important (e.g. CSS data exfiltration vectors, ReDoS in build tools, unintended URL injections).

If you discover a security vulnerability or potential threat in Unboilerplate:

1. **Do NOT open a public issue.**
2. Please report the vulnerability privately via GitHub [Security Advisories](https://github.com/EldrexDelosReyesBula/Unboilerplate/security/advisories/new).
3. Include:
   - Description of the vulnerability.
   - Steps to reproduce or proof of concept.
   - Potential impact on end users or web applications.

---

## Response & Disclosure Timeline

- **Acknowledgment:** Within 48 hours of report submission.
- **Triage & Patch:** We strive to release a patch or advisory within 7-14 days.
- **Public Disclosure:** Coordinated after a fix has been published to npm and CDN.
